# M2 정확도 라벨 작성 기준

`docs/m2-contract.md` 4.1 의 라벨 파일을 쓰는 기준이다. 작업 묶음(`scripts/layout-labels/make-packets.mjs`)의 PNG(줄 상자·번호)와 TXT(줄 목록)를 보고 쓴다. 줄 번호는 TXT 의 `idx` 이다.

## 1. 문단

- **문단 = 편집할 때 함께 다시 흘러야 하는 줄 묶음.** 줄 사이가 자동 줄바꿈(오른쪽 끝까지 차서 넘어감)이면 같은 문단, 강제 줄바꿈(필드·주소·시 행·목록 항목 경계)이면 다른 문단이다.
- 신호: 앞 줄이 열 오른쪽 끝 가까이까지 차고 문장이 이어지면 자동 줄바꿈. 앞 줄이 일찍 끝나고 다음 줄이 새 문장·새 필드로 시작하거나, 들여쓰기·간격·글자 모양이 바뀌면 강제 줄바꿈.
- 제목은 한 문단(두 줄로 넘어간 제목도 하나). 목록은 항목마다 한 문단(넘어간 줄 포함). 글머리 기호가 별도 줄로 잡혔으면 그 항목 문단에 넣는다.
- 행사 일정·주소처럼 줄마다 다른 필드면 줄마다 문단이다. 필드 하나가 두 줄로 넘어갔으면 그 두 줄은 한 문단.
- 표시 수식(따로 선 수식)은 수식 하나(번호 포함)를 한 문단, 역할 `other`.
- 코드 블록·목차 항목은 줄(항목)마다 문단.
- 줄 하나가 두 문단의 글자를 섞어 담았으면(추출 결함) 글자가 많은 쪽 문단에 넣고 `notes` 에 적는다.

## 2. 역할

| 역할 | 기준 |
| --- | --- |
| `header` | 쪽 위 여백의 반복 요소(러닝헤드, 학술지명, 호수), 여백의 장식 탭(세로 섹션 탭 등) |
| `footer` | 쪽 아래 여백의 반복 요소(쪽 번호, 저작권 줄, 슬라이드 하단 막대 글자) |
| `heading` | 장·절 제목, 슬라이드 제목 |
| `list-item` | 글머리·번호 목록 항목 |
| `caption` | 그림·표 설명(`Figure 3.`, `Table 2`, `그림 1`, `표 1` 등) |
| `footnote` | 본문 아래 각주 |
| `other` | 표시 수식, 세로·회전 본문 등 |
| `body` | 그 밖의 본문 |

같은 줄에 여러 머리 요소가 떨어져 있으면(왼쪽 학술지명, 오른쪽 쪽 번호) 각각 다른 문단이다.

## 3. 표

- 격자(2행·2열 이상)로 읽히는 영역. 머리 행(열 제목)은 표에 넣는다. 표 제목·출처·각주는 표 밖 문단(`caption`·`footnote`).
- `rows`·`cols` 는 가장 잘게 나뉜 격자 기준. 병합 셀은 `rowSpan`·`colSpan`.
- `lines` 는 표 안의 모든 줄(필수). `cells` 는 셀 60개 이하 표만 쓴다(선택).
- `bbox` 는 괘선이 있으면 괘선 외곽, 없으면 표 글자 외곽(pt, TXT 좌표계).
- 차트 축 눈금 라벨은 표가 아니라 도형 라벨이다.

## 4. 도형

- 사진·그림·차트·도식. `bbox` 는 그래픽과 그 안 라벨을 덮는 외곽.
- `labels` 는 그래픽 안의 줄(축 이름·눈금·범례·도식 안 글자). 도형 아래·위 설명은 `caption` 문단.
- 쪽 전체 배경 이미지·장식 띠는 도형으로 넣지 않는다.

## 5. 읽기 순서(`items` 순서)

- 사람이 읽는 순서. 머리 요소 → 본문 → 각주 → 꼬리 요소.
- 다단은 열 단위(왼쪽 열 위→아래, 다음 열). 여러 열에 걸친 제목·표·그림은 그 위치의 띠 사이에 둔다.
- 열 안의 그림·표는 열 흐름에서 놓인 자리(위아래 문단 사이)에 둔다.
- 판단이 어려운 줄은 `ignoreLines` 에 넣고 `notes` 에 이유를 적는다. 텍스트가 공백뿐인 줄은 어디에도 넣지 않아도 된다.

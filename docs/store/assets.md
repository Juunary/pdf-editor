# 이미지·아이콘 촬영 목록과 사용자 확인 사항

## 1. 규격

| 항목 | 규격 | 수량 |
| --- | --- | --- |
| 스크린샷 | 1280×800 (또는 640×400), PNG/JPEG, 모서리 둥근 효과·여백 없음 | 1장 이상(권고 5장) |
| 작은 프로모션 타일 | 440×280 | 1장 |
| 아이콘 | 128×128(스토어), 확장은 16·32·48·128 | 매니페스트 `icons`·`action.default_icon`(S3 구현) |

## 2. 촬영 환경

- Windows PC Chrome 정식 최신(Chrome 151 이상), 창 크기 1280×800 에 맞춤. 확장 도구 막대·북마크 막대는 숨깁니다.
- 촬영용 PDF 는 저작권 문제가 없는 문서만 씁니다: 프로젝트 코퍼스의 공공영역·CC BY·공공누리 제1유형 문서(`fixtures/corpus/manifest.json` 의 라이선스 근거 참고) 또는 직접 만든 샘플. 개인정보가 있는 문서 금지.
- 파일 경로·사용자 이름·탭 제목에 개인 식별 정보가 보이지 않게 합니다.

## 3. 스크린샷 목록

| # | 장면 | 설명 문구(대시보드 캡션) | 준비 |
| --- | --- | --- | --- |
| 1 | 문서 열기 직후 뷰어 전체 | Open any PDF in the built-in viewer | 영문 본문 1쪽, 도구 막대 보임 |
| 2 | 검색(Ctrl+F) 결과 하이라이트 | Search across the whole document | 결과 수 표시 |
| 3 | 문단 편집 중(한글 입력) | Edit paragraphs with live reflow | 편집 상자·핸들 보임, 한글 문장 입력 |
| 4 | 표 셀 편집 | Edit a table cell | 괘선 표, 셀 편집 중 |
| 5 | 벡터 도형 선택 + 속성 패널 | Move, resize and recolor vector shapes | 도표 쪽, 선택 상자·핸들·색 패널 |
| 6 | 편집 가능 표시 + 제한 사유 툴팁 | See what can be edited and why not | 초록 실선·주황 점선, 툴팁 |
| 7 | 저장 확인 창 또는 저장 완료 상태 | Save to a file you choose | 저장됨 상태 줄 |

최소 1장은 3번 또는 5번으로 합니다(핵심 기능).

## 4. 프로모션 타일 440×280

- 구성: 아이콘 + 이름 + 한 줄("Edit PDFs in Chrome"). 상표·타사 로고·실제 문서 내용 없음.
- 제작은 사용자가 합니다(스크린샷 캡처와 달리 디자인 작업). 초안 문구: "PDF Editor — Edit PDFs right in Chrome".

## 5. 사용자 확인 필요 문구·항목

| # | 항목 | 이유 |
| --- | --- | --- |
| 1 | 확장 이름 "PDF Editor"(가칭) 상표·기존 등록 확장 이름 검색 | 상표·Web Store 이름 중복 확인은 사용자(D2) |
| 2 | 설명에 쓴 "Chrome" 표기 | Google 상표 사용 지침상 "Chrome 에서 …" 같은 서술적 표기만 사용했는지 확인 |
| 3 | 개인정보 처리 방침 시행일·제공자 표기("Juunary"), 문의처 | 법적 표기는 사용자 결정 |
| 4 | 개인정보 처리 방침 공개 URL | 저장소 `main` 병합 뒤 유효한 링크. 병합 전에는 대시보드에 넣을 수 없음 |
| 5 | 공개 범위(비공개 테스트 → 공개) | D2: 사용자 결정 |
| 6 | 스크린샷에 쓸 문서의 라이선스 | 촬영 문서 출처·라이선스 확인 |
| 7 | 설명의 "기기 안에서 처리" 표현 | 실제 네트워크 요청 확인(실측) 뒤 확정 |
| 8 | Web Store 빌드 매니페스트와 권한 표 일치 | [practices.md](practices.md) |
